# Núcleo QDA — Codificar párrafos (asignar y quitar códigos)

## ¿Para qué sirve?
Marcar fragmentos del texto con códigos para clasificar evidencia y luego poder revisarla, compararla y reportarla.

## Resultado (qué obtenés)
- Pasajes resaltados en el documento.
- Evidencia visible desde la ficha del código (lista de referencias).

## Pasos (desde la interfaz)
1. Abrí un datafile (nota/documento) en el panel central.
2. Seleccioná el párrafo o el fragmento a codificar.
3. Usá la **Command palette** y ejecutá:
   - **Assign code to paragraph** (asignar)
   - **Remove code from paragraph** (quitar)
4. Elegí el código (o crealo según el flujo del entorno).
5. Verificá el resultado:
   - el fragmento queda resaltado
   - en **Códigos → (tu codebook) → (código)** aparece el pasaje en *Referencias de párrafos asignados*.

## Consejos
- Si estás trabajando con varios codebooks, confirmá cuál está activo antes de codificar (ver [[crear_y_cambiar_codebook]]).

## Problemas comunes
- **No me aparece el comando**: revisar que el plugin núcleo QDA esté habilitado.
- **Se asignó al código equivocado**: quitar y volver a asignar.
