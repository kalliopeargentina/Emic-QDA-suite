# Glosario

- **Vault**: carpeta base del proyecto en Obsidian.
- **Datafile**: nota/documento fuente donde está el corpus (texto + propiedades) y donde se codifica/extrae.
- **Codebook**: conjunto de códigos para una etapa/proyecto/equipo.
- **Código**: etiqueta aplicada a un fragmento del texto.
- **Dominio**: conjunto de tipos de entidad y relación (tu “modelo”).
- **Ontología**: definición de tipos (entidad/relación) y reglas.
- **Entidad**: instancia concreta (persona, lugar, organización…).
- **Relación**: vínculo tipado entre entidades, con evidencia.
- **Extracción**: registro derivado de pasajes del texto, con atributos.
- **Reporte**: composición/export (PDF/DOCX) para compartir resultados.
