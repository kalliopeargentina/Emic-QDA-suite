# Reportes — Exportar a PDF y DOCX

## ¿Para qué sirve?
Generar un documento final (PDF y/o Word) a partir de un reporte compuesto.

## Resultado (qué obtenés)
- Archivos `.pdf` y/o `.docx` en la carpeta de salida configurada.

## Pasos (desde la interfaz)
1. Abrí el reporte activo en el compositor.
2. (Opcional) abrí una **previsualización** para verificar paginado/estilo.
3. Ejecutá el comando:
   - **Export active report project** (export del reporte activo), o
   - **Export saved report** (export de un reporte guardado).
4. Elegí formato (PDF/DOCX/ambos) si se ofrece en settings.

## Ajustes relacionados
- Carpeta de salida por defecto.
- Formato por defecto (pdf/docx/both).
- Tamaño de papel.
