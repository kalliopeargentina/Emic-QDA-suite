# Referencia funcional — Entidades y relaciones

**Entidad** = instancia de un **entity type** (Persona, Organización, …) con propiedades literales y relaciones.

**Relación** = instancia de un **relation type** entre dos entidades, con **evidencias** (pasajes del corpus).

Comandos orientativos frecuentes:

- Extract entity / relation from paragraph.
- Create relation / add relation to current entity.
- Add / remove evidence on relation.
- Merge entities, delete entity.
- Validate / reconcile domain graph.
- Export domain definition & knowledge graph.

Flujos: carpeta `03-Dominios-entidades-y-ontologias/`.
