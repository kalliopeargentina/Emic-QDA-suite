# Troubleshooting

## El plugin no aparece / no carga
- Verificar que esté habilitado en **Settings → Community plugins**.
- Verificar que la carpeta del plugin exista en `.obsidian/plugins/<plugin-id>/`.
- Probar **Reload app**.

## No puedo ver/abrir una vista (reports, charts, sidebar)
- Ver si el comando correspondiente aparece en la **Command palette**.
- Si es una vista lateral, probar cerrar/abrir paneles.

## “No exporta” (PDF/DOCX/CSV/PNG)
- Verificar carpeta destino configurada (si aplica).
- Verificar permisos de escritura del vault.
- En PDF/DOCX: suele requerir desktop (si aplica).

## Mobile vs Desktop
- Algunas funciones pueden ser solo desktop (ej. selectores de archivo del SO o exportadores).
- Si algo no aparece en mobile, buscar alternativa (adjuntar desde dispositivo, etc.).
