# Referencia funcional — Tipos de extracción

Un **tipo de extracción** define la “plantilla” de columnas/atributos que tendrá cada **extracción** creada desde texto.

- Se crea con **Create new Extraction Type**.
- Se lista/resume con **Show extraction type overview** (según build).
- Se borra con **Delete Extraction Type** (respetar impacto en datos existentes).
