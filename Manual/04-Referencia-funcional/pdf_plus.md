# Referencia funcional — EMIC PDF++ (resumen orientado a QDA)

**EMIC PDF++** mejora el visor PDF de Obsidian: highlights, plantillas de copia, menús contextuales, opciones de edición de PDF, y acciones hacia **Emic‑QDA**.

### Grupos de comandos frecuentes (orientativos)

- Copiar enlaces / selección / anotaciones.
- Menús de formato de copia y display text.
- Navegación y zoom (sidebar, outline, thumbnails).
- Edición de PDF y páginas (si `enablePDFEdit` y archivo no external).
- Integración Emic‑QDA (menú contextual / toolbar) — ver settings `emicQda*` y flags de visibilidad.
