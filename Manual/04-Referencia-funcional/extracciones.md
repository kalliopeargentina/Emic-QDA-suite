# Referencia funcional — Extracciones (registros)

Una **extracción** es un registro derivado de uno o más **párrafos fuente** del corpus, con atributos definidos por su **tipo**.

Operaciones usuales:

| Operación | Comando orientativo |
|-----------|---------------------|
| Crear | **Extract from paragraph** |
| Añadir fuente | **Add paragraph as source to existing Extraction File** |
| Quitar fuente | **Remove paragraph from extraction** |
| Editar atributos | **Edit extraction attributes** |
| Unir | **Merge another Extraction File into current Extraction File** |
| Borrar | **Delete current Extraction File** |
| Export masivo | **Export all extractions as .csv / .json** |

Flujos: carpeta `04-Extracciones/` en [[../03-Flujos-de-trabajo/00-Mapa-de-flujos]].
