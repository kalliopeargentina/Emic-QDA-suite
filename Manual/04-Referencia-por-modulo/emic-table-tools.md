# Referencia por módulo — Emic Table Tools

## Qué hace
Exportar tablas Markdown a CSV, editar CSV como grilla, insertar CSV como tabla MD, asignar block-id, transponer tabla, menú contextual *Table Tools*.

## Comandos (IDs)
- `emic-csv-create-new`
- `export-table-csv`
- `assign-table-block-id`
- `assign-all-tables-block-id`
- `transpose-table`
- `insert-csv-as-markdown`

## Settings
`defaultExportFolder`, `preferredDelimiter`, `openCsvAfterExport`.
