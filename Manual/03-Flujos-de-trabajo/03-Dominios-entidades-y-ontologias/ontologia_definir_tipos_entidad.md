# Núcleo QDA — Ontología: definir tipos de entidad

## ¿Para qué sirve?
Definir qué “clases” de cosas existen en tu dominio (por ejemplo Persona, Organización, Lugar) y qué propiedades literales pueden tener.

## Resultado (qué obtenés)
- Tipos de entidad disponibles para crear/extractar entidades.

## Pasos (desde la interfaz)
1. Confirmá el **dominio activo** (ver [[dominios_crear_abrir_cambiar]]).
2. Abrí el menú del dominio/ontología.
3. Usá las opciones:
   - **Create new Entity Type**
   - **Edit Entity Type Literal Properties**
4. Definí propiedades literales si corresponde (ej. edad, rol, organización).

## Consejo pedagógico
Si estás explorando (inductivo), podés empezar con pocos tipos y ampliar después.
