# Referencia por módulo — Emic Charts View

## Qué hace
Procesa bloques `emic-charts-view` (YAML) renderizados con `@ant-design/charts`; wizard, templates, wordcount/dataview paths, PNG export opcional.

## Comandos
| id | Desktop only |
|----|---------------|
| insert-emic-charts-view-template | no |
| emic-charts-view-wizard | no |
| import-emic-charts-view-data-csv | **sí** |

## Settings
`theme`, `backgroundColor`, padding 4-side, `dataPath`, `showExportBtn`, `wordCountFilter`.
