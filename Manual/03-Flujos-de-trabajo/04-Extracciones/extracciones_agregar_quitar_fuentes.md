# Núcleo QDA — Extracciones: agregar y quitar fuentes (pasajes)

## ¿Para qué sirve?
Construir una extracción a partir de múltiples pasajes (o corregirla quitando fuentes equivocadas).

## Resultado (qué obtenés)
- Una extracción con varias fuentes (evidencias) o con fuentes corregidas.

## Agregar un párrafo a una extracción existente
1. Abrí el datafile y seleccioná el pasaje.
2. Ejecutá **Add paragraph as source to existing Extraction File**.
3. Elegí la extracción destino.

## Quitar un párrafo de una extracción
1. Abrí el datafile o la extracción (según el flujo del entorno).
2. Ejecutá **Remove paragraph from extraction**.
3. Confirmá.
