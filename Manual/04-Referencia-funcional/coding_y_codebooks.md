# Referencia funcional — Codificación y codebooks

**Codebook** = conjunto de **códigos** y su definición (metadatos, relaciones entre códigos).

Operaciones centrales (nombres en inglés en código; UI puede traducir):

- Asignar / quitar código en párrafo.
- Renombrar, fusionar, dividir códigos.
- Relaciones entre códigos con **relation types**.
- Export definición y export CSV de códigos.
- Resúmenes y matrices (coocurrencias) según menú del libro de códigos.
