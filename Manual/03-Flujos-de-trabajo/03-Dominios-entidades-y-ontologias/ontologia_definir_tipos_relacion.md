# Núcleo QDA — Ontología: definir tipos de relación

## ¿Para qué sirve?
Definir qué vínculos existen entre entidades (por ejemplo “es empleado de”, “depende de”, “vive en”) y entre qué tipos aplica.

## Resultado (qué obtenés)
- Tipos de relación disponibles para crear relaciones con evidencia.

## Pasos (desde la interfaz)
1. Confirmá el **dominio activo**.
2. Abrí el menú del dominio/ontología.
3. Usá las opciones:
   - **Create new Relation Type**
   - **Edit Relation Type**
4. Definí el tipo y, si aplica, sus restricciones (qué tipos puede conectar).
