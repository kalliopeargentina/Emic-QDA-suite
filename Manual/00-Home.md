# Manual de EMIC Plus QDA

Este manual explica **cómo usar EMIC Plus QDA desde la interfaz** (menús, comandos, botones y ajustes). Está pensado con un criterio “tipo ATLAS.ti / NVivo”: de **trabajo de campo** a **análisis** y finalmente a **reportes**.

## Empezar acá

- Si querés una visión general: [[00-Resumen]]
- Si querés entender la pantalla y las secciones: [[01-Interfase-de-usuario]]
- Si querés el recorrido recomendado (pipeline QDA): [[03-Flujos-de-trabajo/00-Mapa-de-flujos]]
- Si querés instalar/actualizar: [[01-Instalacion-y-actualizacion]]
- Si es tu primera vez: [[02-Primeros-pasos]]
- Referencia funcional QDA: índice en [[04-Referencia-funcional/coding_y_codebooks]] y resto de `.md` en esa carpeta.
- Referencia por plugin: [[04-Referencia-por-modulo/emic-qda]] y demás archivos de la carpeta.

## Recorrido recomendado (en una línea)

Trabajo_de_campo → Codificación_y_codebooks → Dominios_entidades_y_ontologías → Extracciones → Reportes → Tablas/CSV → Gráficos (PDF solo como apoyo cuando haga falta).
