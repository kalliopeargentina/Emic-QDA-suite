# Núcleo QDA — Validar y exportar el grafo (dominio + knowledge graph)

## ¿Para qué sirve?
Detectar inconsistencias (tipos, relaciones) y exportar el modelo/grafo para compartirlo o analizarlo fuera del entorno.

## Resultado (qué obtenés)
- Un chequeo/validación del dominio.
- Export(s) del dominio y/o del grafo en formatos disponibles.

## Validar / reconciliar
1. Confirmá el dominio activo.
2. Ejecutá **Validate/Reconcile Domain Graph**.
3. Revisá el resultado en la UI (mensajes/avisos) y corregí lo necesario.

## Exportar
Desde el menú del dominio o la command palette, usar:
- **Export Domain Definition (JSON/Turtle)**
- **Export Knowledge Graph (JSON/GraphML/GML/CSV)**
