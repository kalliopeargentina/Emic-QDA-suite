# Núcleo QDA — Relaciones entre códigos

## ¿Para qué sirve?
Expresar vínculos entre conceptos (por ejemplo, jerarquías, equivalencias o asociaciones) para ordenar el análisis y apoyar reportes.

## Resultado (qué obtenés)
- Tipos de relación definidos.
- Relaciones creadas entre códigos.

## Definir tipos de relación
1. Abrí el menú del codebook (ver en [[01-Interfase-de-usuario]]: “Menú del libro de códigos”).
2. Usá las opciones:
   - **Create code relation type**
   - **Edit code relation type**
   - **Remove code relation type**

## Crear/editar/remover relaciones
1. Abrí la ficha de un código.
2. Ejecutá:
   - **Create relation between codes**
   - **Edit relation from current Code**
   - **Remove relation from current Code**
3. Elegí el código relacionado y el tipo de relación.
