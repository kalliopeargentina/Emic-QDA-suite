# Núcleo QDA — Extracciones: exportar

## ¿Para qué sirve?
Sacar las extracciones como dataset para análisis, auditoría o integración con otras herramientas.

## Resultado (qué obtenés)
- Un `.csv` y/o `.json` con todas las extracciones (según el comando).

## Pasos (desde la interfaz)
Usar la **Command palette** y ejecutar:
- **Export all extractions as .csv**
- **Export all extractions as .json**

## Consejo
Exportar CSV es ideal para planillas; JSON es ideal para pipelines o integraciones.
