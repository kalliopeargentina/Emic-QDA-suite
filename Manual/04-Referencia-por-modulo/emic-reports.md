# Referencia por módulo — Emic Report Architect (Emic‑Reports)

## Qué hace
Componer **report projects**, **style templates** JSON en vault, preview paginado HTML, export **PDF** y **DOCX**, **quick print** de nota activa.

## Comandos (IDs en código)
| id | Uso |
|----|-----|
| open-report-composer | Compositor |
| open-style-template-editor | Editor plantillas |
| open-style-preview | Preview estilo |
| export-active-report-project | Export proyecto activo |
| print-active-note | Quick print nota |
| export-saved-report | Picker reportes guardados |

## Settings destacados
`uiLanguage`, `defaultOutputFolder`, `templatesFolder`, `defaultPaperSize`, `defaultFormat`, `openPreviewOnExport`, `quickPrintTemplateId`.

## Plataforma
Export PDF real vía Electron/Chromium — orientado a **desktop**.

Flujos: `05-Reportes-y-exportacion/`.
