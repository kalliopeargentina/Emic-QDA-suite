# Núcleo QDA — Renombrar, fusionar y dividir códigos

## ¿Para qué sirve?
Refinar el codebook cuando el análisis avanza: corregir nombres, unificar códigos duplicados o separar referencias que deberían pertenecer a dos códigos distintos.

## Resultado (qué obtenés)
- Un codebook más consistente (mejor recuperación y reportes).

## Renombrar un código
1. Abrí la ficha del código.
2. Ejecutá **Rename code**.
3. Confirmá el nuevo nombre.

## Fusionar códigos
Útil cuando dos códigos representan lo mismo.

1. Abrí la ficha del código “destino” (el que va a quedar).
2. Ejecutá **Merge another Code File into current Code File**.
3. Elegí el otro código a fusionar.
4. Verificá que la evidencia quede bajo un solo código.

## Dividir (split) un código
Útil cuando un código quedó “sobrecargado” y querés separar parte de sus referencias.

1. En la ficha del código, identificá las referencias a mover.
2. Seleccioná las referencias según el mecanismo que ofrezca la vista.
3. Ejecutá **Split selected references into another Code File**.
4. Elegí/creá el código destino.

## Problemas comunes
- **Perdí consistencia de nombres**: definí una convención (singular/plural, mayúsculas, etc.) y aplicala con renombrado.
